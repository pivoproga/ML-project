## Описание

Система распознавания именованных сущностей (NER) для текстов объявлений торговых площадок (Авито, Wildberries, Ozon и др.). Извлекает четыре типа атрибутов:

| Класс | Описание | Пример |
|---|---|---|
| `BRAND` | Бренд / производитель | Samsung, Самсунг, Apple |
| `MODEL` | Модель товара | Galaxy S22 Ultra, iPhone 14 Pro |
| `PRICE` | Цена | 45 000 ₽, 650$, 45к руб |
| `CONDITION` | Состояние | б/у, как новый, 10/10 |

Базовая модель: **bert-base-multilingual-cased** (178M параметров, 104 языка).  
Достигнутые метрики: **Test F1 = 0.9997**, Precision = 0.9996, Recall = 0.9998.

## Использование

```bash
# Полный пайплайн: генерация данных → обучение → инференс → визуализация
python main.py --all

# Только генерация синтетических данных (3000 примеров)
python main.py --generate

# Только генерация с указанием числа примеров
python main.py --generate --samples 5000

# Загрузить WikiANN и смешать с синтетикой
python main.py --convert-mave

# Обучить модель (на ранее сгенерированных данных)
python main.py --train

# Обучить на смешанном датасете (синтетика + WikiANN)
python main.py --train --use-combined

# Демо-инференс на тестовых объявлениях
python main.py --infer

# Визуализация метрик обучения
python main.py --visualize
```
